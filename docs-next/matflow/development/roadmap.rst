Documentation roadmap
=====================

This prototype establishes the navigation and reader journeys. It is not a
promise that the proposed runtime features exist.

Before replacing the existing documentation:

* Migrate generated API, CLI and configuration schema pages.
* Generate parameter constructors and input/output relationships from component definitions.
* Verify solver compatibility and run tutorials on the documented platforms.
* Add reviewed materials-science case studies with licensed images and citations.
* Publish branch previews and confirm their retention and access policy.
* Review redirects, version selection, canonical URLs and search indexing.

Possible later work includes provisioned environments, a browser-based trial,
additional parameter value classes and new solver integrations. Track runtime
feature requests separately from documentation migration.
