MatFlow project
===============

MatFlow brings materials-science task schemas, parameter types and workflows to
the hpcflow engine. Its reusable components connect tools across microstructure
generation, crystal plasticity and analysis.

Start with :doc:`install/index` or explore :doc:`workflows/index`.
See the project repository for contributors and citation metadata:
`MatFlow on GitHub <https://github.com/hpcflow/matflow>`_.
