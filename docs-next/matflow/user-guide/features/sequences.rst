Sequences and repeats
=====================

Sequences generate multiple task elements by varying inputs. Repeats let you run more than one case with the same nominal inputs, for example with different random outcomes.

Decide whether varying inputs should be paired or combined before creating a large sweep. Check the number of elements on a small example; nested combinations can grow quickly.

See :doc:`../hello-world` for a small task schema and :doc:`../../reference/catalogue`
for built-in component definitions.

The `existing how-to guides <https://docs.matflow.io/stable/user/how_to/index.html>`_
contain the detailed syntax while it is being migrated.
