Groups
======

Groups describe collections of elements that can be consumed together by downstream work. They are useful when a reduction or fit needs several simulation results as one input collection.

Choose grouping rules around the scientific operation: for example, combine the cases used for one fit while keeping different materials separate. Check group membership before submitting costly calculations.

See :doc:`../hello-world` for a small task schema and :doc:`../../reference/catalogue`
for built-in component definitions.

The `existing how-to guides <https://docs.matflow.io/stable/user/how_to/index.html>`_
contain the detailed syntax while it is being migrated.
