Loops
=====

Loops represent repeated execution through a defined part of a workflow. Their termination and data dependencies need to be explicit.

Begin with a bounded example. Check which task outputs are fed into the next iteration, which inputs remain fixed, and how intermediate files are retained.

See :doc:`../hello-world` for a small task schema and :doc:`../../reference/catalogue`
for built-in component definitions.

The `existing how-to guides <https://docs.matflow.io/stable/user/how_to/index.html>`_
contain the detailed syntax while it is being migrated.
