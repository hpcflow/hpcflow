Meta-tasks
==========

Meta-tasks provide a higher-level way to compose task behavior. They help package recurring workflow structure for reuse.

First develop and verify the underlying tasks. Introduce a meta-task when the same composition appears repeatedly, and document its public inputs and expected outputs.

See :doc:`../hello-world` for a small task schema and :doc:`../../reference/catalogue`
for built-in component definitions.

The `existing how-to guides <https://docs.matflow.io/stable/user/how_to/index.html>`_
contain the detailed syntax while it is being migrated.
