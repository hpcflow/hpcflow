Built-in component sources
==========================

Component definitions are the source of truth for the schemas, executable labels
and parameter types used by a template. These counts include internal definitions;
they are not a count of supported public workflows.

* **Parameters**: 110 source definitions. `Browse parameters YAML <https://github.com/hpcflow/matflow/blob/1eec25503f153e6779d9253b660816bd7204d8d0/matflow/data/template_components/parameters.yaml>`_
* **Task schemas**: 89 source definitions. `Browse task schemas YAML <https://github.com/hpcflow/matflow/blob/1eec25503f153e6779d9253b660816bd7204d8d0/matflow/data/template_components/task_schemas.yaml>`_
* **Environments**: 1 source definitions. `Browse environments YAML <https://github.com/hpcflow/matflow/blob/1eec25503f153e6779d9253b660816bd7204d8d0/matflow/data/template_components/environments.yaml>`_
* **Command files**: 23 source definitions. `Browse command files YAML <https://github.com/hpcflow/matflow/blob/1eec25503f153e6779d9253b660816bd7204d8d0/matflow/data/template_components/command_files.yaml>`_
