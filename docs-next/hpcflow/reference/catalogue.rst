Built-in component sources
==========================

Component definitions are the source of truth for the schemas, executable labels
and parameter types used by a template. These counts include internal definitions;
they are not a count of supported public workflows.

* **Parameters**: 13 source definitions. `Browse parameters YAML <https://github.com/hpcflow/hpcflow/blob/7aa0b37c444a3850c1d30e7d1fccc3f2696aeb66/hpcflow/data/template_components/parameters.yaml>`_

* **Environments**: 2 source definitions. `Browse environments YAML <https://github.com/hpcflow/hpcflow/blob/7aa0b37c444a3850c1d30e7d1fccc3f2696aeb66/hpcflow/data/template_components/environments.yaml>`_
* **Command files**: 6 source definitions. `Browse command files YAML <https://github.com/hpcflow/hpcflow/blob/7aa0b37c444a3850c1d30e7d1fccc3f2696aeb66/hpcflow/data/template_components/command_files.yaml>`_
