Glossary
========

.. glossary::

   Workflow template
      A reusable YAML or Python description of tasks and their inputs.

   Workflow
      A concrete instance with parameter values, execution state and artifacts.

   Task schema
      A reusable definition of inputs, outputs and actions for a computation.

   Task
      A use of a task schema within a workflow.

   Element
      An individual case of a task, with its own input combination.

   Action
      A command, script or related operation in a task schema.

   Environment
      A definition of software setup and executable commands.

   Command file
      A named file used or produced by an action.

   Parameter
      A typed value used as an input or output.

   Resource
      An execution requirement such as a shell, scheduler or core count.
