Environments and specifiers
===========================

An environment gives names to software setup and executable instances. Specifiers can distinguish multiple definitions with the same name, such as different solver versions.

Use a version specifier when reproducibility requires a particular installation. Avoid fixing the version in a reusable schema unless the computation depends on that version. See the installation section for a minimal executable definition.

See :doc:`../hello-world` for a small task schema and :doc:`../../reference/catalogue`
for built-in component definitions.

The `existing how-to guides <https://hpcflow.github.io/docs/stable/user/how_to/index.html>`_
contain the detailed syntax while it is being migrated.
