Resources
=========

Resources describe how work executes: shell, scheduler, core counts and related settings. An executable instance also describes the resources it supports.

Check the intersection of workflow requests, executable support and scheduler limits. Inspect generated jobscripts before scaling up. Account and queue settings belong in machine configuration.

See :doc:`../hello-world` for a small task schema and :doc:`../../reference/catalogue`
for built-in component definitions.

The `existing how-to guides <https://hpcflow.github.io/docs/stable/user/how_to/index.html>`_
contain the detailed syntax while it is being migrated.
