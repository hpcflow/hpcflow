Element sets
============

An element set supplies a collection of task inputs, sequences and related settings. It helps describe distinct families of cases within one task.

Keep element sets separate when they represent different input definitions or execution needs. Check the resulting elements before adding downstream dependencies.

See :doc:`../hello-world` for a small task schema and :doc:`../../reference/catalogue`
for built-in component definitions.

The `existing how-to guides <https://hpcflow.github.io/docs/stable/user/how_to/index.html>`_
contain the detailed syntax while it is being migrated.
